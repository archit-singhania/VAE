# Bundled fonts

These font files are bundled so VAE renders consistently without a runtime
network request:

- Manrope (Regular, SemiBold, Bold)
- Playfair Display (Medium)
- JetBrains Mono (Regular)

Each family is distributed under the SIL Open Font License 1.1. The source
families and license details are available from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
